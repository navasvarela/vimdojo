vimdojo

Learn Vim motions, Neovim workflows and your own init.lua by solving tiny puzzles in real Neovim. Every key counts: beat par for three stars.

Play the demo Install the plugin

How it works

  1. 1 Get a puzzle

    A short snippet of code or prose, and a goal: fix the typo, land on the bug.

  2. 2 Solve it with motions

    Use real Vim keys. The timer starts on your first keystroke, and every key is counted.

  3. 3 Beat par

    Match the level's par in keys and time for three stars. Then find a shorter way.

Try it

The demo needs a physical keyboard.

Install

Neovim 0.10 or newer. No dependencies. Then run :VimDojo.

lazy.nvim

{ "%VITE_REPO%", cmd = "VimDojo", opts = {} }

packer.nvim

use({ "%VITE_REPO%" })

vim-plug

Plug '%VITE_REPO%'

rocks.nvim

:Rocks install vimdojo

setup() is optional; see the configuration options.

Curriculum

Every level's solution is proven in real Neovim on every change, and pars are honest. Want to add a level? Packs are plain JSON: write your own.
